# 02 beam pointing 정답

공식 (barrel tower n, Δθ = π/160 = 1.125°, R_in = 2805 mm, 기울기 α = 1°):

1. θ_n = 90° − (n + ½)·Δθ
2. L = R_in / sin θ_n  (원점에서 tower 축을 따라 DRC 앞면까지의 거리)
3. x0 = L·tan α  → position = (x0, 0, 0) mm
4. direction = (−sin α, cos α·sin θ_n, cos α·cos θ_n)

왜 이렇게 되는가: tower 축 방향은 (0, sin θ_n, cos θ_n) 이다 (phi = 90°, 즉 +y 쪽).
beam 을 이 축에서 x 방향으로 α 만큼 기울이면 direction = cos α·(축) − sin α·(x̂) 이다.
gun 을 x = x0 에 두면 beam 은 x 방향으로 sin α 씩 줄어들어서, 축 방향으로 x0 / tan α 만큼 갔을 때 x = 0 이 된다.
그 지점이 앞면 (축 방향 거리 L) 이 되도록 x0 = L·tan α 로 잡는다.

endcap tower m (40 ~ 74) 은 θ_m = 45° − (m − 40 + ½)·Δθ, L = z_front / cos θ_m (z_front = 2805 mm) 이고 나머지는 같다.

확인: `python3 advanced/02_beam_pointing/check_beam.py --position <x0> 0 0 --direction <dx> <dy> <dz> --tower <n>`
이 "OK" 를 출력하면 맞다. sim/SteeringFile_o3_gun.py 의 p0 ~ p3 은 아래 표의 tower 0, 20, 40, 57 과 같다.
